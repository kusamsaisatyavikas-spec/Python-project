## How to Run the Python Programs

1. Install Python 3 on your computer.
2. Open the folder containing the `.py` files in Visual Studio Code.
3. Open a program file, for example `case_01.py`.
4. Open the VS Code terminal.
5. Run:

   ```bash
   python case_01.py
   ```

6. Check the displayed output and try the other test cases by changing the sample values in the program.
